# Bathusi Plumbing Landing Page

A simple static landing page for a plumbing service, designed to communicate reliability and trust quickly.

## Project Structure

- `index.html` — main landing page content and markup
- `style.css` — page styling, layout, responsive behavior
- `script.js` — lightweight interaction for navigation link highlighting

## Features

- Sticky top navigation with quick links and a prominent call button
- Hero banner with headline, supporting text, and CTA buttons
- Trust strip with license, response time, pricing, and emergency service points
- Featured services section with six core plumbing services
- Clean responsive layout for desktop and mobile

## Usage

1. Open `index.html` in a browser.
2. Or serve the folder with a static server, e.g.:
   ```bash
   python3 -m http.server 8000
   ```
3. Then visit `http://localhost:8000`.

## Customization

- Update the phone number in `index.html` for the call and WhatsApp links.
- Replace the hero image URL in `index.html` with your own image or local asset.
- Add additional sections or pages by editing `index.html` and linking to new files.

## Notes

- The page currently uses a small JS stub in `script.js` for active navigation link behavior.
- All styling is contained in `style.css`, so it is easy to maintain and extend.
